
Structure: A basic clothing store site with a server file, a product data file, and three public files (HTML page, stylesheet, JavaScript).

Server: Runs on Node.js. It serves the webpage files and has one API route that returns the list of products from a data file as JSON.

Product data: A small file listing a few clothing items, each with an ID, name, price, and category.

Webpage: A single HTML page with a heading and an empty container where products get added.

JavaScript: Fetches the product list from the server and inserts each product's name and price into the page.

Stylesheet: Basic styling — simple font, products laid out in a wrapping row, each with a plain border and padding.

What it does:Loads the page, fetches products from the server, and displays them as a plain list of name and price. No cart, no checkout, no filtering, no search, no images, no luxury styling  just showing products.

To run:Start the server, then open it in a browser.
